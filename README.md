# 🤖 DroidLingo

Учим **Android Studio** и **Kotlin** как в Duolingo — от чайника до профи. Без жизней и таймера 💚

## Что внутри

- 🏠 **Главная** — тропа из 7 разделов по дорожной карте:
  1. 🚀 Старт → 2. 🎨 Интерфейсы на XML → 3. ⚙️ Экраны и навигация → 4. 📋 Списки →
  5. 💾 Хранение данных → 6. 🌐 Интернет и API → 7. ✨ Современный Android
- 🏁 **Чекпоинты-проекты** в каждом разделе: Первое приложение, Калькулятор, Анкета, Todo, Todo с сохранением, Погода из API, Todo на Compose
- 🃏 **Карточки** — 14 колод, переворачиваются по клику, кнопки «Знаю / Повторить»
- 🎯 **Закрепление** — смешанные задания: выбор, правда/ложь, пары, порядок кода, пропуски
- 📝 **Тесты** — по каждому разделу + финальный экзамен (60%+ открывает дальше)
- 💻 **Песочница** — тренажёр кода: пиши Kotlin и запускай прямо в браузере (свой мини-интерпретатор: циклы, функции, списки, `?.`, `?:`, `Random`). 10 задач от «Привет, мир!» до «Угадай число», у каждой есть решение
- 💜 **Kotlin** — 7 уровней: переменные → условия → циклы → функции → null-безопасность → коллекции и лямбды → классы + чекпоинт «Угадай число»

## Запуск

Просто открой `index.html` в браузере — или подними сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Прогресс, XP, серия дней и рекорды хранятся в `localStorage`.
