# 🤖 DroidLingo

Учим **Android Studio** и **Kotlin** как в Duolingo — от чайника до профи. Без жизней и таймера 💚

## Что внутри

- 🏠 **Главная** — тропа из 4 разделов: Старт → Интерфейс → Логика → Профи
- 🃏 **Карточки** — флеш-карточки по всем темам (переворачиваются!)
- 🎯 **Закрепление** — смешанные задания: выбор, правда/ложь, пары, порядок кода
- 📝 **Тесты** — тесты по разделам + финальный экзамен (60%+ открывает дальше)
- 💻 **Песочница** — тренажёр кода: пиши Kotlin и запускай прямо в браузере (свой мини-интерпретатор!)
- 💜 **Kotlin** — курс из 6 уровней: переменные → условия → функции → классы → коллекции → профи

## Запуск

Просто открой `index.html` в браузере — или подними сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Прогресс, XP, серия дней и рекорды хранятся в `localStorage`.
